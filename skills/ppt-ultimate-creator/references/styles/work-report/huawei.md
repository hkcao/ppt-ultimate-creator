# 华为汇报风格

工作汇报下的默认子风格，适用于经营分析、阶段成果、项目进展及决策沟通。结合[工作汇报指南](../work-report.md)中的官方浅色 16:9 模板使用；用户选择其他模板时遵循其选择。

## 来源与适配边界

改编参考 [ppt-forge 华为式专业汇报](https://github.com/zuiho-kai/huawei-style-ppt-skill/blob/d4c5124093503f0e58d661b11026340c8a634453/ppt-forge/references/ppt-style-huawei.md)，2026-09-16 查阅；该项目注明源自 Clowder AI。[MIT 许可与署名](../../licenses/ppt-forge-MIT.txt)随技能保留。

这是一套第三方视觉建议，不是华为官方规范认证或品牌授权。本次用户确认约束优先，其次是所选模板固定项，再应用本页补充规则。官方模板原件与此文档分别管理，不擅改 Logo、保密标记或版权声明。

## 视觉参数

白底与深色文字构成主体，红色只强调关键结果或重点系列；减少厚重阴影、发光、立体柱和密集边框。原模板已有主题色时先取实际值；缺少指定值或仅使用本风格时，可用以下参考色板，记录在 brief 的共享 design_tokens，逐页只引用角色名和例外。

| 角色 | 参考值 | 用途 |
| --- | --- | --- |
| accent | #D33941 | 重点数据、当前步骤、主要系列 |
| text | #555757 | 正文；对比不足时加深 |
| muted | #898989 | 次要标注；观看不可读时加深 |
| border | #DDDDDD | 弱分隔，不为填满页面而画框 |
| background | #FFFFFF | 主背景 |
| compare | #30B5C5 | 对比系列，辅以标签/线型 |

这些 RGB 数值来自第三方建议，不声明与某 Pantone 色号严格等价。风险/完成状态配文字标签，不能只靠红绿判断；系列颜色跨页一致。

中文仍用微软雅黑、英文仍用 Times New Roman，数学表达仍插入原生公式；来源中的 Arial 不覆盖用户已有约定。主标题约 28–32pt、重点指标约 28–36pt 可作为起点，正文按观看距离和实际画幅调整，不能为高密度缩字硬塞。模板固定字体冲突在已有启动确认中说明。

## 页面类型

| 页面任务 | 组织方式 | 检查重点 |
| --- | --- | --- |
| 成果/KPI | 重点数值、单位、基期与解释，次要指标降权 | 数据有来源，变化有比较口径 |
| 工作全景 | 按业务层次分组，必要时用直角面板/矩阵 | 不将不同权重的模块机械等分 |
| 项目推进 | 阶段、交付结果与依赖沿阅读方向排列 | 箭头表示真实关系，当前状态明确 |
| 经营分析 | 主图为主体，旁侧解释变化与原因证据 | 结论与图表一致，轴/单位可读 |
| 问题改进 | 问题证据、行动、验证结果连续呈现 | 无结果时标待验证，不提前称有效 |
| 方案对比 | 相同维度与条件并排，突出真正差异 | 不预设旧方案坏、新方案好 |
| 论证页 | 围绕有依据的判断安排必要图、表或机制 | 证据支持判断，不为凑面板强加媒体 |

标题区、主体区、来源/口径区保持稳定；默认简洁、偏直角，已有模板形状优先。总结条、红色细线按需使用；品牌飘带、科技光线和大块红底不是必填项。

## 验收

先看能否迅速找到主题、证据和结果，再看细节是否可读。不规定每页必须 3–6 组或固定红色比例。有依据的结果页可用结论标题，计划/问题/机制页不强造结论。保留原生文字、图表、公式与语义图形，不采用参考技能的图片型交付边界。
